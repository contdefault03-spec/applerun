# Credits

Alfredo Applerun only uses assets that are free to use (CC0 or CC-BY), assets supplied by
the project owner, or assets generated procedurally in code. No real brand names or logos.

Third-party files are downloaded by `node tools/fetch-assets.mjs`, which tries the original
host first and falls back to a public GitHub mirror of the *same* file (some networks block
polyhaven.com / ambientcg.com).

time; the ocean and island replace it.

## Generated in code

Everything else — terrain, roads, buildings, props, vehicles, weapons, furniture, textures
and sound effects — is procedurally generated by the game's own code.
